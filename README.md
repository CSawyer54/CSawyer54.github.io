# Game Center

Hub page for my browser games, live at **https://csawyerprof.github.io/**

| Game | Play | Source |
| --- | --- | --- |
| Fruit Plop: a fruit-merge game with a Shake button | https://csawyerprof.github.io/fruit-plop/ | [fruit-plop](https://github.com/CSawyerProf/fruit-plop) |
| Randomino: a neon falling-block game with random polyominoes | https://csawyerprof.github.io/randomino/ | [randomino](https://github.com/CSawyerProf/randomino) |

Each game lives in its own repo and is served by GitHub Pages under this same domain. To add a game, give it its own Pages repo and add a card to `index.html`.
